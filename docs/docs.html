Build your first project

  1. Open the editor. Use the button in the header to launch the visual builder.
  2. Add an event. Choose an event such as Player Join and drag it onto the workspace.
  3. Add behavior. Put an action in the event body and fill in its inputs. Use reporters and operators for values.
  4. Use your code. Review the generated JavaScript and copy it into your Bloxd.io world code.

The editor generates source code; it does not connect to your world or run the code for you.

Workspace basics

The editor has three main areas:

  • Category rail and block list: select a category to browse its blocks, or search across block names and descriptions.
  • Workspace: arrange event blocks and attach actions, controls, and values. Use the zoom buttons or mouse wheel to zoom; drag the open canvas to pan.
  • Code and output: generated JavaScript updates as you make changes. Hover over toolbox blocks for a short description.

Events and callbacks

Green event blocks define callback functions. Their names and parameter reporters match the editor's callback catalog. Place action and control blocks in the event body to run them when the callback fires.

Callback availability, arguments, and return behavior are defined by Bloxd. Check the official callback reference before relying on a callback.

onPlayerJoin = (playerId) => { api.sendMessage(playerId, "Welcome!"); };

Blocks and API

Blocks are organized by category. Actions call API methods or perform operations; reporter blocks produce values that can be nested into compatible sockets. Boolean operators produce conditions, while control blocks contain sequences of actions.

  • Events: callback entry points such as Player Join and Tick.
  • Game API: methods from the editor's Bloxd API catalog. Each block lists its arguments, and its description links to the method documentation.
  • Logic and operators: if, if / else, repeat, comparisons, boolean logic, arithmetic, and vector helpers.
  • Custom Styled Text and Item Operator: helpers for building styled text and item attribute values.

API blocks are a convenience for composing code, not a guarantee that a method or argument is accepted by the current game version. See the official API reference.

Variables and functions

Create variables in the Variable category. Each variable adds a reporter, a set block, and a change block. Right-click a created variable in the toolbox to delete it; its blocks and generated declaration are removed from the workspace.

Create custom functions in the Function category. The category provides a function definition block and a call block. Place a definition in the workspace to generate its body; a call without a placed definition generates an empty function stub.

Save and load .bb files

Use SAVE to download your complete project as a .bb (Bloxd Block) file. The file stores the blocks and their connections, input values, workspace positions and zoom, plus user-created variables and functions.

Use LOAD to choose a .bb file from your device. Loading replaces the current workspace with the saved project. Keep the file somewhere you can find it; the editor does not upload or sync it.

TipA .bb file is a project file for this editor, not JavaScript source. Copy the generated code from the code panel when you want to use it in a world.

Generated JavaScript

The code panel translates your workspace into JavaScript. Expressions entered in expression inputs are emitted as code; ordinary inputs are converted to simple JavaScript values. Inspect generated expressions and arguments before using them in a world.

Use the official Bloxd documentation for current runtime behavior and API details.

Troubleshooting

A block will not attach to an input

Only compatible value shapes fit a socket. Statement blocks belong in event or function bodies, and reporter or boolean blocks fit value inputs.

My .bb file does not load

Confirm that you selected a valid .bb file exported by the editor. An invalid, unsupported, or damaged file is rejected without replacing the open workspace.

The generated code does not work in my world

Check that the callback and API method exist in the current Bloxd reference, then verify every argument and expression. The editor does not execute or validate code against the game.
